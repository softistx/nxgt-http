# Roadmap

What `@nxgt/typespec` gives a spec, and what is coming. Each convention is the
shape the `@nxgt/*` packages already send, compiled to OpenAPI 3.1 and
generated by `@nxgt/openapi-codegen` in CI before it ships.

## Now

- **Error replies.** The envelope `@nxgt/openapi-hono` sends, and the
  400, 401, 403, 404, 409, 422, 429 and 500 responses, with any other status
  through `ErrorResponse<Status>`.

## Next

- **Pagination.** Offset (`page`, `pageSize` → `{ items, total, page,
  pageSize, pageCount }`) and cursor (`after`, `limit` → `{ items,
  nextCursor }`) templates, as `@nxgt/drizzle` and `@nxgt/mongo` page.
- **Authentication.** Bearer and session-cookie schemes, as `@nxgt/janus`
  reads them, and their 401 and 403.
- **Common scalars.** Ids, e-mail, URL and timestamps.
- **Headers.** Idempotency key, `ETag`, rate limits.

## Later

- **Resource templates.** List, read, create, update and delete in one
  template, with filter, sort and fields parameters.
